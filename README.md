## أبرز المشاريع

### FocusFlow
منصة لإدارة المشاريع والمهام، تهدف إلى تنظيم سير العمل وتبسيط إدارة الفرق من خلال واجهات حديثة ولوحة تحكم متكاملة.

**المميزات:**
- إدارة المشاريع والمهام.
- نظام صلاحيات متعدد (Role-Based Access Control).
- لوحة تحكم تفاعلية.
- تصميم حديث باستخدام Tailwind CSS.
- بنية قابلة للتوسع والتطوير.

### Atlas System
نظام ويب لإدارة الامتحانات العملية وتنظيم تدوير المجموعات الطلابية بشكل مرن.
